# Week 2 – Data Collection, Cleaning & Preprocessing

YuvaIntern Logistics Data Analysis project.

## Objective
Prepare the Week 1 logistics dataset for reliable analysis and machine learning.

## Methods
- Missing-value assessment and imputation
- Duplicate removal
- Date conversion
- Categorical standardization
- IQR-based outlier detection
- StandardScaler preprocessing
- Cleaned dataset export

## Structure
```text
data/
  logistics_data.csv
  logistics_data_cleaned.csv
notebooks/
  Week2_Data_Cleaning_Preprocessing.ipynb
reports/
  Week2_Data_Cleaning_Preprocessing_Report.docx
README.md
requirements.txt
```

## How to Run
Open the notebook in Jupyter, JupyterLab, or Google Colab and run cells from top to bottom.

The dataset is simulated for educational/internship use.
